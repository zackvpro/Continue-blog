# 笔记

现代化理论兴起于美国，欧美学者在通过对发展中国家的发展模式与发达国家的早期发展模式的比较中，对现代化问题形成了丰富的研究成果。
詹姆斯·奥康内尔指出，现代化概念关系到三个基本方面：1. 对事物的相互联系和因果的存在，有坚定的信念。这个新年维持着一种连续不断地、系统性的和创造性的知识探索——换言之，便是具有分析因果关系式的观念和创造发明的观念；2. 产生于第一种观念，并加以促进的工具和技术的大量增加；3. 在个人和社会结构的基础上形成了接受不断变化的愿望，与此同时又具有保留个人和社会特色的能力
亨廷顿认为，现代化是一个革命的、复杂的、系统的、全球的、长期的、又阶段的、同质化的、不可逆转的和进步的过程。
阿尔蒙德认为，现代化主要是两个政治变量（政府权力、人民参政）与两个经济变量（财富和福利）的进步的过程。
但总的来说，现代化的涵义是从经济、政治和观念的三个维度理解的。

对三个概念的区分：

|       | 与前现代有关的 | 与现代有关的 |
| ----- | ------- | ------ |
| 时间意义上 | 传统的     | 现代的    |
| 过程意义上 | 传统社会    | 现代化    |
| 属性意义上 | 传统性     | 现代性    |
总的而言，现代化的讨论有着工业革命后对社会剧变的讨论，有着以发达国家为标杆的社会形态演变的讨论，也有着以公民行为、观念改变的讨论。现代化问题属于对不同国家的社会演变的相似性和差异性的讨论的问题，并限定在近200年的历史中。

精英—制度主义分析框架的六条理论预设：
1. 阶层预设：精英与大众，精英间有权力精英（政治部门）与财富精英（经济部门），权力精英的高层是统治精英。
2. 精英支配预设：统治精英数量相比总体极少，但在重大政治、经济事务，尤其是制度设计与政策选择上，有支配性影响。
3. 理性人预设：精英意志主要出于自身的理性和利益诉求，尽管会受到历史或他国观点的影响。
4. 制度预设：精英的权力与利益受到既有规则的规制和约束，因规则实为精英间利益的边界，这些边界约束着精英在其中行动。
5. 环境预设：任何国家都处在一定的国际体系中。国家间既能享受到技术扩散和制度扩散的好处（主要来自体系中最发达国家），也容易受到来自其他国家的竞争压力甚至军事威胁。
6. 现代化非中性预设：现代化对权力精英、财富精英与大众的权力和利益的影响并非中性，而是受现代化过程的不同，使不同方的获益不平等。
根据以上假说，得到一个框架：某国能否实现现代化，取决于该国统治精英是否选择有利于现代化的制度与政策；这又取决于现代化及其结果是否符合精英们，尤其是统治精英的权力与利益诉求；而该国政治经济模式构成了约束统治精英的初始约束条件。

---
初始的政治经济模式决定了精英的权力与利益结构，决定了权力精英与财富精英在该结构所处的问题，同时也决定了权力精英、财富精英与大众之间的关系，进而造就了不同的权力精英与财富精英的类型。
国际环境指现代化情境下的工业化与全球化，国内环境则包含特定的制度背景和权力关系。在环境的约束下，由前现代阶段的政治经济模式沿革而来，不同国家的权力精英与财富精英（可被分类为不同类型：垄断型权力精英、共治型权力精英，食利型财富精英、生产型财富精英）的权力和利益结构不同。
在前现代阶段，权力精英和财富精英有两种可能的关系：没有宪法或法治的约束，权力精英支配财富精英；存在正式制度约束，财富精英可与权力精英形成博弈的关系，借助各种制度不同程度上约束权力精英。

>[!NOTE] 精英的类型特征
>垄断型权力精英，控制权力方式威权化
>共治型权力精英，受民主制度的约束
>食利型财富精英，控制着土地、矿产，也可通过控制行政资源对经济资源进行分配，类似于“租金”的概念
>生产型财富精英，通过技术研发、生产制造，为社会提供产品或服务来获得财富和经济利益

在现代化的过程中，大众的财富绝对量基本是上升的，大众的权利基本上是有改善的，因而国家内的大众总体上是持支持态度的。
但现代化对精英的权力与利益的影响更加复杂，不仅取决于他们获得的权力与利益的总量，还取决于他们获得的权力与利益的比例或份额。在现代化过程中，精英获得的权力与利益包括在国内的绝对利益，和与他国进行竞争时的影响力的提升。但某些情况下，大众在现代化过程中获得了更高比例的影响力，这样精英的权力与利益会受到相对损失。
这种相对损失体现在两方面：
1. 精英和大众的相对实力发生变化：大众的动员和组织能力的提高、思想观念的提升和解放、自由和权利的增加，使得大众的力量相对提升，对统治精英形成限制。
2. 权力精英与财富精英的相对食利发生变化：现代化过程需要权力精英依靠财富精英进行，财富精英得到权力与利益在比例上的让渡，这就使得权力精英受到相对损失。
这种复杂关系使得统治精英对现代化时而支持时而反对，部分支持部分反对，有的国家支持有的国家反对。
总而言之，大致呈现这四种态势，而这四种态势使得统治精英在不同阶段可能有不同的态度。
![[现代化的精英—制度主义理论：基于跨国类型学的比较研究 1.png]]
在实际现代化进程中，统治精英的权力与利益时多元，这也构成了统治精英效用函数的约束条件。一般而言，统治精英需要考虑三个关键问题：
- 可统治性的问题，即政治生存问题。需要在压制成本和包容成本之间寻求平衡。
- 统治租金的问题，即权力与利益的足够的比例与份额的问题。
- 国家间竞争导致的政治压力问题。国家间的压力会传导至国内，例如军事竞争压力大，统治精英就需要财富精英推进现代化，来抵御竞争压力。
统治精英这样就因权财比例的变化的利益驱动以及其主观认知的改变，采取了不同方案，而不同路径下的国家权力与财富的总量的变化也有差异，这样便可以分类为以下四种：

|                |     | 权力与财富的总量             |                      |
| -------------- | --- | -------------------- | -------------------- |
|                |     | 增加                   | 减少                   |
| 统治精英的<br>再分配效应 | 增加  | 进取路径<br>现代化程度提供，统治强化 | 掠夺路径<br>现代化程度降低，统治强化 |
|                | 减少  | 包容路径<br>现代化程度提高，统治弱化 | 溃败路径<br>现代化程度降低，统治弱化 |

从现代化路径的另一种角度下，权力精英与财富精英的关系决定着不同的现代化路径以及不同的现代化结果。


|         | 垄断型权力精英                                     | 共治型权力精英                                    |
| ------- | ------------------------------------------- | ------------------------------------------ |
| 食利型财富精英 | 食利型权威模式<br>沙特、蒙博托时期的刚果（金）                   | 食利型共治模式<br>内战前的美国南方、<br>19世纪中叶到20世纪中叶的拉美国家 |
| 生产型财富精英 | 发展型权威模式<br>朴正熙时代的韩国、弗朗哥时期的<br>西班牙、李光耀时期的新加坡 | 发展型共治模式<br>1688年后的英国、1945年后的日本和<br>德国      |
*注*：19世纪中叶到20世纪中叶的拉美国家属于食利型共治模式的缘由：精英们参与政治比较普遍，有投票权，但经济是状元模式，主要依靠占有土地和矿产获得回报

从经验上来看，食利型共治模式的长期发展潜力不足，后期经济与现代化容易出现停滞。这主要是因为，食利型财富精英转型为生产型财富精英时有困难，需要对整个土地制度、政商关系、劳动力流动进行彻底的变革，阻力很大。
尽管权威体制下统治精英都是垄断型的，但出现发展型与食利型的分化的原因可能在于，国家有没有丰富的自然资源，尤其是现代化尤其需要的土地、石油、矿产等资源。如果没有，且面临外部的军事竞争压力，统治精英会需要依靠生产型财富精英，进而塑造出发展型权威模式。发展型权威模式成型后，大众、财富精英与权力精英的力量对比又作为因素，推动国家可能转型为发展型共治模式；也可能回到保守化。
那么食利型共治模式下，可能是向食利型权威模式倒退，因大众参与的加强威胁统治精英的权力、挑战食利型精英获取租金的模式，造成统治精英滑向权威型；可能向发展型共治模式转型，因大众力量对精英形成挑战或外部压力促动转型等。
同时，我们也可以发现，生产型财富精英主导的国家更容易出现现代化的进行，因生产型倾向于塑造生产、经营与技术创新的制度政策。

# 笔者按

本文在精英-制度主义的分析框架下，通过大众、权力精英、财富精英的三类行动主体的互动关系进行分析。基于权力精英占强影响力地位的前提，通过权力精英和财富精英的不同组合，形成了食利型权威、发展型权威、食利型共治和发展型共治等不同的现代化模式。
这四种类型很好地描述了各国现代化的共性与差异性，该分类视角大部分情况下能够自圆其说，并且没有一味照搬“人民的力量具有决定性”、“生产力决定生产关系”的学术视角，是对大众的力量的合理的简化忽视。
本文的主要问题在笔者看来有点以下数点：
一是假设预设时对财富精英与大众的联合力量的重视程度不够；
二是近200年内，各国，尤其是发展中国家的现代化的转型路径，受到两次世界大战与“冷战”的影响是极大的，不管是在现代化初期的初始政治经济制度这一方面，还是在三类行动主体的影响力占比这一方面。
三是隐含着“发展型共治”模式是现代化最终模式的观点，但从当下全球，尤其是发达国家集体右转的视角而言，恐怕是有疑问的。共治型统治精英滑向权威型统治精英存在具体哪些驱动因素，生产型精英转向获取“租金”又存在哪些因素。这些也是值得该框架去完善的。

这篇博客文章对现代化的精英-制度主义理论（源自包刚升2024年的研究框架）进行了结构化且基本准确的总结。文章对六个理论预设和2x2类型学（垄断型/共治型权力精英与食利型/生产型财富精英）的提炼，有效地抓住了该比较政治模型的核心机制。

**优点：** 从现代化的宏观定义到微观层面的精英互动的逻辑推演非常连贯。作者在文末的独立点评展现了很强的分析严谨性。特别是在发达国家近期频繁出现民粹主义和制度性右转的当下，精准指出了该框架潜在的“目的论”偏见（即默认“发展型共治”是最终的稳定进化状态），这一洞察非常敏锐。

**不足与分析盲区：**

1. **排版与清晰度：** 描述四种现代化路径（进取、掠夺、包容、溃败）的部分由于表格排版混乱，掩盖了再分配效应与精英选择之间原本清晰的因果链条。
    
2. **理论盲点：** 虽然作者正确指出了框架对“财富精英+大众结盟”以及宏观历史外部冲击（如冷战）的忽视，但遗漏了一个关键的经济维度：**技术颠覆**。从“食利型”向“生产型”精英的转变往往不仅是内部的制度选择，更是技术范式的变革迫使旧有寻租模式在经济上失效的结果。
    
3. **制度粘性：** 笔记对食利系统为何如此坚韧缺乏深入探讨。食利精英并非被动地抵制变革；他们会主动利用巨额经济剩余来捕获国家机器，形成主动压制生产型精英出现的负反馈循环。
    

**结论：** 这是一篇扎实的学术读书笔记。若想进一步提升分析的深度，作者应超越纯历史视角的批判，尝试将此框架应用于当代的“民主倒退”（democratic backsliding）现象，以检验“共治型”模型解释力的边界。
